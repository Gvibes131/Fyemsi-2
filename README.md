# Fyemsi Cakes and Events

Premium responsive website.

## Structure
- `index.html` — page structure
- `css/style.css` — styling
- `js/script.js` — interactions
- `images/` — replace placeholders with the real brand images

## Image paths
Use files such as `images/hero.jpg`, `images/owner.jpg`, `images/service-1.jpg`, and `images/gallery-1.jpg`.

The current design uses visual placeholders so the site remains intact until real images are added.
